Soal Ujian Sertifikasi Kompetensi

Bidang Keahlian: Pengembangan Perangkat Lunak
Projek: Laundry Point of Sales (POS) Ecosystem

  I. Skenario

         Project Brief: Laundry POS & Customer Tracking Tahap perencanaan dan
         desain telah selesai. Anda sekarang berada di tahap Implementasi. Tugas Anda
         adalah membangun sistem laundry yang saling terintegrasi melalui API.

             1. Web Admin: Dashboard untuk petugas mengelola transaksi dan status
                  cucian.

             2. REST API: Backend Laravel sebagai jembatan data.
             3. Mobile App: Aplikasi untuk pelanggan memantau status cucian mereka.

  II. Alur Bisnis & Relasi Data (Business Flow)

         Agar tidak rancu dalam implementasi, pahami alur kerja sistem berikut:

             1. Master Data: Admin menyiapkan data services (daftar harga) dan data
                  users dengan role 'customer'.

             2. Registrasi Profil: Saat users dengan role 'customer' dibuat, sistem juga
                  harus membuat data di tabel customers untuk menyimpan nomor HP
                  dan alamat.

             3. Proses Transaksi:
                       Petugas Admin login ke Web Admin.
                       Admin membuat transaksi di tabel transactions dengan memilih
                           customer_id dan admin_id (petugas yang sedang login).
                       Status awal transaksi otomatis menjadi 'antrian'.

             4. Update Operasional: Admin mengubah status transaksi di Web secara
                  berkala (Antrian -> Dicuci -> Disetrika -> Siap Diambil).

             5. Monitoring Mobile: Pelanggan login ke Mobile App, sistem memanggil
                  API untuk mengambil data dari tabel transactions yang memiliki
                  customer_id sesuai user yang login. Pelanggan melihat perubahan
                  status secara real-time.
